# Temperature Control System

## Goal

Build a simple automated temperature-control system,
starting with a software simulation and gradually
developing it into a physical prototype.

## Current version

The system simulates a temperature sensor and decides
whether a cooling fan should be ON or OFF.

### Control logic

- Temperature >= 30°C → Fan ON
- Temperature < 30°C → Fan OFF
