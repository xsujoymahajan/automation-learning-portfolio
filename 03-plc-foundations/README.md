Objective: Control the Nano's built-in LED through code.
Hardware: Arduino Nano + USB cable.
Software: Arduino IDE.
Input: None.
Output: Built-in LED.
Concepts learned: setup(), loop(), pinMode(), digitalWrite(), delay(), HIGH, LOW.
Experiment: Changed the delay from 1000 ms to 200 ms, then 100 ms.
Result: Verified that changing the program parameters changes the physical LED's timing.
Key principle:
HIGH → wait → LOW → wait → repeat
