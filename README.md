## Working convention

Each project should have its own numbered folder and a `README.md` explaining its goal, controls/logic, files, tests, and next steps. Keep generated PLC build artefacts in the project's `PLC/build/` directory and avoid mixing them with project notes.

The workspace-level guide is available one folder above this repository: [`../README.md`](../README.md).
